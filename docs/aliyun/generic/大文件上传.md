大文件上传
通过本指南介绍如何使用分块上传脚本进行大文件上传。

概述
对于大文件上传，Packages 仓库提供了分块上传功能，支持将大文件分割成多个块进行上传，避免因文件过大导致的超时问题。

我们提供了两个分块上传脚本供您使用：

Shell 脚本：chunk_upload.sh

下载地址：https://agent-install-beijing.oss-cn-beijing.aliyuncs.com/packages_upload/chunk_upload.sh
适用于 Linux/macOS 环境
Python 脚本：chunk_upload.py

下载地址：https://agent-install-beijing.oss-cn-beijing.aliyuncs.com/packages_upload/chunk_upload.py
适用于所有支持 Python3 的平台
功能特性
✅ 支持大文件分块上传（默认分块大小：100MB）
✅ 支持断点续传（Shell 脚本）
✅ 使用异步方式合并分块，避免长时间连接导致的超时问题
✅ 自动计算文件 MD5 并验证
✅ 详细的日志输出和进度显示
✅ 完善的错误处理
使用 chunk_upload.sh
依赖要求
bash (版本 4.0+)
curl (支持 HTTPS)
base64 (用于 Basic Auth)
md5sum 或 md5 (用于计算 MD5)
stat (用于获取文件大小)
dd (用于读取文件分块)
基本用法
用户名: {username}
密码: {password}
./chunk_upload.sh \
  --repo-url "https://packages.aliyun.com/api/protocol/{org_id}/generic/{repo}" \
  --file-path "path/to/artifact" \
  --version "1.0.0" \
  --file "/path/to/file.tar.gz" \
  --username "{username}" \
  --password "{password}"
完整参数示例
./chunk_upload.sh \
  --repo-url "https://packages.aliyun.com/api/protocol/{org_id}/generic/{repo}" \
  --file-path "my-project/artifacts/my-artifact" \
  --version "1.0.0" \
  --file-name "my-artifact" \
  --file "/path/to/my-artifact-1.0.0.tar.gz" \
  --username "{username}" \
  --password "{password}"
参数说明
--repo-url : 必填， 仓库 URL，示例: https://packages.aliyun.com/api/protocol/{org_id}/generic/{repo}
--file-path: 必填， 制品文件路径（即包列表中的包名），示例: path/to/artifact
--version: 必填， 上传版本，示例: 1.0.0
--file: 必填， 要上传的制品文件路径，示例: /path/to/file.tar.gz
--username: 必填， 认证用的用户名，参见上面的账密信息，示例: {username}
--password: 必填， 认证用的密码，参见上面的账密信息，示例: {password}
--file-name: 选填， 制品名称（可选)，示例:my-artifact

工作流程
启动上传会话：调用 API 创建上传会话，获取 uploadUuid 和 location
分块上传：将文件分成 100MB 的块，逐个上传每个分块（Shell 脚本支持断点续传）
计算文件 MD5：自动计算文件的 MD5 值
触发异步合并：调用异步合并 API，传递文件 MD5 作为 digest
轮询合并状态：每 3 秒查询一次合并状态，最多轮询 20 分钟
制品包与当前仓库关联：关联仓库与制品包，传递文件 MD5 作为校验
配置参数
脚本中的可配置参数（可在代码中修改）：

分块大小：100MB（CHUNK_SIZE = 100 * 1024 * 1024）
轮询间隔：3 秒（POLL_INTERVAL = 3）
轮询超时：20 分钟（POLL_TIMEOUT = 1200）
注意事项
文件大小：脚本适用于所有大小的文件，会自动进行分块上传
网络稳定性：Shell 脚本支持断点续传，网络中断后可以继续上传
认证信息：用户名和密码会用于生成 Basic Auth，请妥善保管
URL 编码：脚本会自动对 filePath、version 和 fileName 进行 URL 编码
SSL 证书：脚本使用 --insecure 选项忽略 SSL 证书验证，生产环境请根据需要调整
