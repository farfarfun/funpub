# 大文件上传

`funpub` 内置阿里云 Packages generic 仓库的分块上传，不需要下载或运行仓库外的脚本。

## 配置认证

CLI 从 `funsecret` 读取仓库地址和认证信息。以下配置只需为每个仓库执行一次：

```bash
funsecret write https://packages.aliyun.com/api/protocol/{org_id}/generic/{repo} \
  funpub aliyun generic {repo_name} repo_url
funsecret write {username} funpub aliyun generic {repo_name} username
funsecret write {password} funpub aliyun generic {repo_name} password
```

不要通过命令行参数传递用户名或密码。

## 命令行上传

```bash
funpub upload /path/to/artifact.tar.gz my-project/artifacts/my-artifact \
  --version 1.0.0 --repo-name {repo_name}
```

默认情况下，文件大小超过 100MB 时会自动使用分块上传；较小的文件使用普通上传。
如果同一路径和版本已存在，命令会失败以避免意外覆盖；传入 `--overwrite` 可明确允许覆盖。

## Python API

已配置 `funsecret` 时，只需要仓库名称：

```python
from funpub import get_publisher

publisher = get_publisher("aliyun", repo_name="{repo_name}")
result = publisher.upload_file(
    filepath="/path/to/artifact.tar.gz",
    path="my-project/artifacts/my-artifact",
    version="1.0.0",
)
print(result.url, result.md5)
```

若在一次性脚本中直接构造发布器，请从环境变量读取配置，而不要在源码中写入凭据：

```python
import os

from funpub import get_publisher

publisher = get_publisher(
    "aliyun",
    repo_url=os.environ["FUNPUB_ALIYUN_REPO_URL"],
    username=os.environ["FUNPUB_ALIYUN_USERNAME"],
    password=os.environ["FUNPUB_ALIYUN_PASSWORD"],
)
```

`upload_file` 在文件大于 `chunk_threshold` 时自动分块；`chunk_threshold` 默认等于
`chunk_size`，两者默认均为 100MB。调用方可以在创建发布器时调整：

```python
publisher = get_publisher(
    "aliyun", repo_name="{repo_name}", chunk_size=50 * 1024 * 1024
)
```

分块上传每块默认 100MB，合并状态每 3 秒轮询一次，20 分钟后超时。上传过程会计算
并校验 MD5；服务端返回的校验和不一致时抛出 `ChecksumMismatchError`，合并超时时抛出
`MergeTimeoutError`，其他远端失败抛出 `PublishError`。
